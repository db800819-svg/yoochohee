# images

Tripo 뷰어에서 캡처한 이미지를 이 폴더에 `asset.png` 라는 이름으로 넣으세요.

```
web/images/asset.png
```

- 배경이 단색(흰색·회색 등)이면 페이지가 **자동으로 배경을 지워** 투명하게 만듭니다.
- 배경이 조금 남거나 에셋이 깎여 보이면 `web/app.js` 의 `CONFIG.tolerance` 값을 조절하세요.
  - 배경이 남는다 → 값을 올린다 (예: 30 → 42)
  - 에셋 가장자리가 깎인다 → 값을 내린다 (예: 30 → 20)
- 이미 배경이 투명한 PNG라면 아무 설정도 필요 없습니다.

`placeholder.svg` 는 `asset.png` 가 없을 때 보여주는 임시 도형입니다.
