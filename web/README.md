# 3D 에셋 인터랙티브 씬

Tripo에서 만든 3D 에셋이 화면에 둥둥 떠 있고, 마우스를 움직이는 방향으로 기울며 따라오는 웹 페이지.

## 1. Tripo 내보내기 설정

| 항목 | 선택 |
|------|------|
| 포맷 | **GLB** |
| 텍스처 해상도 | **2k 권장** (4k도 되지만 로딩이 느려짐) |
| 버튼 | 노란색 **내보내기** (왼쪽 "보내기"는 Blender 연동이라 불필요) |

GLB 하나에 메시 + 재질 + 텍스처가 모두 들어가서 웹에서 파일 한 개만 올리면 끝난다.
FBX/OBJ는 텍스처가 별도 파일로 떨어지고, USD/STL/3MF는 웹용이 아니다.

## 2. 파일 넣기

내려받은 파일 이름을 `model.glb`로 바꿔서 아래 위치에 저장한다.

```
web/models/model.glb
```

다른 이름을 쓰고 싶으면 `main.js` 맨 위 `CONFIG.modelUrl` 값을 바꾸면 된다.

## 3. 실행

`index.html`을 더블클릭하면 브라우저 보안 정책(CORS)에 막혀 GLB가 로드되지 않는다.
반드시 로컬 서버로 열어야 한다.

```bash
cd web
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

Node가 있다면 `npx serve web` 도 동일하게 동작한다.

## 4. 움직임 조절

`main.js` 상단 `CONFIG` 값만 바꾸면 된다.

| 값 | 의미 |
|----|------|
| `fitSize` | 에셋 크기 (화면에서 얼마나 크게 보일지) |
| `tiltX` / `tiltY` | 마우스 상하·좌우에 따라 기울어지는 각도 |
| `driftX` / `driftY` | 마우스를 따라 이동하는 거리 |
| `ease` | 따라오는 속도. 작을수록 더 느긋하고 부드럽다 (0.02~0.15 권장) |
| `floatAmp` / `floatSpeed` | 둥둥 떠다니는 진폭과 속도 |
| `spin` | 가만히 둘 때 스스로 도는 속도. `0`이면 정지 |
| `parallax` | 카메라가 반대로 움직이는 양 (깊이감) |

## 참고

- three.js는 CDN(jsDelivr)에서 불러오므로 `npm install` 이 필요 없다.
- GLB가 없으면 파란 임시 큐브가 대신 표시되고, 화면 위에 안내 문구가 뜬다.
- 모델에 애니메이션이 포함돼 있으면 자동으로 재생된다.
- 배포는 GitHub Pages / Netlify / Vercel에 `web/` 폴더를 그대로 올리면 된다.
